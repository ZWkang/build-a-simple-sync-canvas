# Frontend

Browser-only React application extracted from TanStarter's frontend stack.

```bash
bun run dev
bun run test
bun run typecheck
bun run build
```

Kept: React 19, TanStack Router, TanStack Query, Tailwind CSS 4, and shadcn/ui configuration.

Excluded: TanStack Start, Nitro, server functions, API routes, authentication, Drizzle/Postgres, Docker, and deployment configuration.
